# Contributing to Squint

Squint is distributed under the Apache-2.0 license. Contributions are
accepted under the same license and should preserve the package's support for
Python 3.10 through 3.13 on Windows and Linux.

Install the checkout in editable mode with standard pip:

```text
python -m pip install -e .
```

The full research workflow is planned for Task 15. This task covers only the
installable package boundary and version CLI.
